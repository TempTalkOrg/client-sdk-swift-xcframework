# LiveKit Swift SDK (TempTalk fork) — xcframework

Prebuilt `LiveKit.xcframework` for iOS, built from the TempTalk fork of the
[LiveKit Swift SDK](https://github.com/livekit/client-sdk-swift). Each tag is the SDK version
(`LiveKitSDK.version`); the zip is attached to the GitHub Release of the same name.

This repository is generated by the SDK's release scripts. Do not edit it by hand.

## Usage

```swift
.package(url: "https://github.com/TempTalkOrg/client-sdk-swift-xcframework", exact: "<version>")
```

and depend on the `LiveKit` product. It brings in three binary targets: `LiveKit`,
`LiveKitWebRTC` and `RustLiveKitUniFFI`. Requires iOS 15 or later.

The TempTalk signaling messages are plain Swift types in the `LiveKit` module (`Livekit_TTCallRequest`,
`Livekit_TTCallResponse` and the types they contain), used by `ConnectOptions(ttCallRequest:)`,
`Room.ttCallResp` and `LiveKitError.response`. The app needs no SwiftProtobuf or generated code for them.
